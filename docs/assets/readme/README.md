## Project-authored assets

- `pipeline.svg`: original N.148i pipeline diagram.
- `example-original.png`: PNG rendering of `images/example.ppm`.
- `example-n148i-q50.png`: decoded N.148i reconstruction at quality 50,
  chroma 4:2:0.
- `example-error-8x.png`: absolute RGB difference between the two preceding
  images, multiplied by 8 to make error visible.

The three example images derive from the project fixture by Micilini Roll and
are distributed under the project's MIT License.
